* **Rule 1 (Proper Classes as First-Class Entities):** 
  In Morse–Kelley class theory, proper classes exist natively alongside sets.
  * $x \in V \iff \text{Set}(x)$ (A set is any class that is a member of another class / belongs to the universal class $V$).
  * $\text{Proper}(X) \iff \neg \text{Set}(X)$ (A proper class is not a member of any class).

* **Rule 2 (No Kuratowski Pairs for Proper Classes):**
  * NEVER define ordered pairs of proper classes using the Kuratowski construction $\{\{A\}, \{A, B\}\}$. Kuratowski pairing requires $A, B$ to be members of sets, which is mathematically false for proper classes.
  * ALWAYS use **Dunaev Tagged Ordered Pairs** with the fixed tags 1 and 2:
    $$[A,B]_D = \operatorname{mark}(A,1) \cup \operatorname{mark}(B,2), \qquad \operatorname{mark}(X,k) = \{\langle u,k\rangle_K \mid u \in X\}.$$
    The tags are constants, not a bound variable `tag`. For sets, $\operatorname{rank}([A,B]_D) = 1 + \max(\operatorname{rank} A, \operatorname{rank} B)$; proper classes remain pairable because their elements are still sets.

* **Rule 3 (Full Impredicative Comprehension):**
  * In MK, class comprehension $\{ x \in V \mid \phi(x) \}$ permits formulas $\phi$ whose bound quantifiers range over **all classes** (unlike NBG, which restricts bound quantifiers to sets).

* **Rule 4 (Syntax vs. Semantics Separation):**
