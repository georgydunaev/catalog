Branch: Coq Math & Logic Theories (Reference Only)

This branch contains academic Coq formalizations. These are reference repositories and must NOT be modified unless explicitly instructed by the user.

Coq Repositories Summary

  • goedel/
    Subject: Gödel's First and Second Incompleteness Theorems formalization in Coq (NNtheory.v, Deduction.v, subProp.v, codeList.v).

  • zfc/
    Subject: Zermelo-Fraenkel set theory with Axiom of Choice formalization in Coq (Plump.v, Replacement.v, Cartesian.v, 3_Regularity.v).

  • HoTT/
    Subject: Homotopy Type Theory library checkout for Coq.

  • Proofs/
    Subject: Category theory and Yoneda Lemma formalizations in Coq (Yoneda.v, Yoneda2.v, functional_completeness.v).

  • Jech/
    Subject: Exercises from Thomas Jech's "Set Theory" textbook in Coq (Jech.v).

  • VerifiedMathFoundations/
    Subject: Deduction theorem and universal quantifier instantiation proofs in Coq (Deduction.v, UNIV_INST.v).

  • Other Specialized Coq Repos:
    Alpha/ (00.v), FirstOrderTheory/ (First-order logic), InsertSort/ (Verified sort), Lambek/ (Lambek calculus), MathLogic/ (Propositional logic), ModalLogic/, ProofTheory/ (QandPA.v).
