Repository: problem_with_exceptions

Path: /botworkspace/problem_with_exceptions
Toolchain: CakeML & HOL4 (Higher-Order Logic)

MEANING & PURPOSE:
Investigates the CakeML monadic translator for Standard ML programs. Specifically explores how to translate and verify monadic functions that raise and handle exceptions (without references or mutable arrays) by reusing existing translation configurations rather than defining a new global state configuration from scratch.

Key Files

  • exceptionProgScript.sml: HOL4 proof script defining state_exn (Fail1 string | Fail2 int) and configuring the monadic translator with with_exception.
  • exception2ProgScript.sml: Second iteration testing inheritance of exception translations without re-instantiating state types.
  • Holmakefile: Build rules for compiling the HOL4 theories with CakeML libraries.
