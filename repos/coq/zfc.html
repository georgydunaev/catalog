Model: Peter Aczel's constructive encoding of Zermelo-Fraenkel set theory inside inductive type theory.

THE ACZEL INDUCTIVE SET MODEL (Sets.v):
Inductive Ens : Type := sup (A : Type) (f : A -> Ens).
A set is represented as an inductive tree indexed by a carrier type A with branching function f.

Key Theorems & Files

  • Russell.v:
    Theorem Russell : forall E : Ens, (forall E' : Ens, IN E' E) -> False.
    Constructive proof of the non-existence of a universal set via Russell's paradox on Ens.
