THE MATHEMATICAL PROBLEM WITH KURATOWSKI PAIRS:
1. Spurious Rank Elevation: Standard Kuratowski pairs (x, y) = {{x}, {x, y}} force rank((x, y)) = max(rank(x), rank(y)) + 2, pushing tuples two levels higher in the cumulative hierarchy $V_\alpha$.
2. Proper Class Failure: In Morse-Kelley class theory, if A or B is a proper class, Kuratowski pairing fails because proper classes cannot belong to sets.

The Dunaev Tagged Pair Construction

mark(A, n) = { {0, n} } ∪ { { {{a}}, n } | a ∈ A }
pair(A, B) = [A, B]_D = mark(A, 1) ∪ mark(B, 2)
pr1(L)     = { a | { {{a}}, 1 } ∈ L }
pr2(L)     = { b | { {{b}}, 2 } ∈ L }

Why It Works:

  • Collision-Free Tagging: The marker {0, n} has 0 elements in its first component (since $0 = \emptyset$). Any element pair { {{a}}, n } has 1 element in its first component ($\{\{a\}\} \neq \emptyset$). Thus, marker tags can never collide with element data.
  • Disjointness: Since tag $1 \neq 2$, $\text{mark}(A, 1) \cap \text{mark}(B, 2) = \emptyset$.
  • Non-Emptiness: Even when $A = B = \emptyset$, $[A, B]_D = \{\{0, 1\}, \{0, 2\}\} \neq \emptyset$.
  • Minimal Rank Growth: $\text{rank}([A, B]_D) = 1 + \max(\text{rank}(A), \text{rank}(B))$.
  • Proper Class Pairing: Works universally for both sets and proper classes without universe escalation.

Formal Theorems in Obelisk (dunaev_tagged_pairs_proof.ML)

  1. Left Projection: forall A B. pr1 ([A, B]_D) = A
  2. Right Projection: forall A B. pr2 ([A, B]_D) = B
  3. Injectivity (Constructive Derivation): forall A B C D. [A, B]_D = [C, D]_D -> A = C /\ B = D
    Note: Derived strictly via Leibniz congruence (eq_cong), symmetry (eq_sym), and transitivity (eq_trans) applied to projection theorems. Eliminates ad-hoc injectivity axioms.
  4. Non-Emptiness: forall A B. [A, B]_D <> EmptySet
