  • obelisk_cli.py (v3.2.0, Poly/ML 5.7.1):
    Universal Commands:
    - obelisk status: Reports Poly/ML compiler engine, 3-stage NBG/MK/Tarski health, and theorem stats.
    - obelisk repl: Launches interactive NBG + Tactic proof shell with goal display and backtracking.
    - obelisk check <file|thm> (or obelisk verify): Checks a .nbg/.odl/.ML file or named theorem.
    - obelisk theorem <name>: Fuzzy-resolves, normalizes, and inspects certified NBG proof terms.
    - obelisk test [filter]: Runs the 73 automated unit & regression tests in tests/.
    - obelisk list [--category]: Displays certified NBG theorems, MK suites, and Stage III schemas.
    - obelisk demo: Runs full 3-stage propositions-as-types verification suite in Poly/ML.
    - obelisk bundle (or obelisk build): Compiles single-file monolith into dist/obelisk_unfolded.ML.
    - obelisk quote <schema>: Evaluates Stage III meta-schemas under Tarski stratification.
    - obelisk export-lp: Exports Dedukti / LambdaPi (.lp) formal proof certificates.
