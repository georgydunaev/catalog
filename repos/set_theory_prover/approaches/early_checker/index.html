Status: PRESERVED HISTORICAL STRATUM (NOT DEAD CODE)

Preservation Rationale: Contains checker.ML (5,177 lines). The 4,941-line restored block represents good, working first-generation sequent rules temporarily set aside while testing short STLC scratch experiments. Never delete.

Key Files & Historical Role

  • checker.ML (130KB): First-generation classical Morse-Kelley sequent calculus checker. Uses explicit de Bruijn indices and earlier sequent representations before newchecker.ML.
  • debrujin.ML: Pure de Bruijn shifting and substitution functions.
  • copy_content.ML: Text transformation utilities extracting theorem statements between PDF markers.

Why It Was Succeeded by newchecker.ML

While sound, the early checker lacked dependent type integration and dynamic tactic management. Its core rules were refactored into newchecker.ML and dependent_syntax.ML.
