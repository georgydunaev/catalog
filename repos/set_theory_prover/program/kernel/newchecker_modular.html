Modular NewChecker Architecture (program/newchecker/)

Path: /botworkspace/set_theory_prover/program/newchecker/
System & Theory: MKTD1-system / MKTD1-prover (MKTD1-framework, MKTD1-theory Axiomatic Sequent Calculus Kernel)
Master Loader: program/newchecker/all.ML & top-level program/newchecker.ML

PURPOSE & PERFORMANCE MOTIVATION:
Originally authored as a 14,033-line monolith, newchecker.ML previously took ~12–15 seconds to evaluate in Poly/ML because compiling it also triggered types/demo.ML (which loaded foundations.ML and entries.ML and executed interactive test examples). By decomposing the kernel into 12 modular units under program/newchecker/, developers and AI agents can load only the exact layers required (AST, printers, rules, definitions, or PDF generator) in 0.3 to 1.5 seconds.

1. The 12 Modular Files

Module Lines Core Responsibilities
00_preamble.ML ~160 Compiler options (reportUnreferencedIds), ANSI colors, error handling, and libs/000_use_all_libs.ML.
01_core_ast.ML ~2,370 Core AST types, judgments, de Bruijn operators, typetheory.ML, lense.ML, Nat.ML, Unit.ML, and the delimited PDF generation source marker block ((*** TO PDF PART BEGIN ***) to (*** TO PDF PART END ***)).
02_globvars.ML ~700 Global variables (GlobVar: vx, vy, vz, vA, vB, vphi, vpsi, tA, tB), FormulaASCII, and sequent notation shortcuts.
03_printers.ML ~3,160 Pretty printing system: dStr_init, Truth_Expre_dStr, Class_Expre_dStr, TyVariable_Expre_dStr, Assign1 functors, and show helpers.
04_subst.ML ~1,960 Free-variable analysis (isFree), capture-avoiding simultaneous substitution (simSubst), and alpha-equivalence (alpha_eq).
05_rules.ML ~1,300 Axioms A01–A13, Gentzen inference rules (Ident, Cut, Weakening, ImplL, ImplR, AndR, ForaR, ExisR), and the 3-pass verification pipeline (check, checkPlus, checkPipeline). Preserves Category B (Hilbert calculus).
06_definitions.ML ~630 Conservative definition store (signature KERNEL_DEFINITIONS, structure KernelDefinitions :> KERNEL_DEFINITIONS). Checks closedness, parameter matching, and non-circularity.
07_theorems.ML ~950 Milner LCF theorem encapsulation (signature THMS, structure ThmWithPrf, structure Thm). Preserves Category C (structure ThmWithoutPrf).
08_tactics.ML ~1,240 Backward tactics (Ident_tac, Cut_tac, ImplR_tac, AndR_tac), tacticals (THEN, ORELSE), GoalTree interactive proof calculus (set_goal, ee, ss, get_thm), and computable side-condition evaluator (NoncomputableSideCondition).
09_entries.ML ~1,470 Catalog entity specifications (signature Entry, Sortnames, structure Entry). Preserves Category A (Morse-Kelley + Tarski specification).
10_pdf_generator.ML ~40 PDF / LaTeX listing extraction engine: copyContentBetweenMarkers scans code between (*** TO PDF PART BEGIN ***) and (*** TO PDF PART END ***), emitting CONTENT.ML and parsing **L / L** comments into LaTeX documentation.
11_meta_and_main.ML ~70 Metatheoretic helpers (CMetaTruth_Expression), constV, loads types/demo.ML, and defines structure NewChecker.
all.ML ~25 Master topological loader compiling all 12 modules in sequence.

3. Preservation & Compatibility Invariants

  • Top-Level newchecker.ML Delegation: The file program/newchecker.ML delegates cleanly to PolyML.use "newchecker/all.ML"; and defines structure NewChecker, preserving 100% backward compatibility for existing callers (such as program/html_generator.ML).
  • Preservation of Commented Historical Blocks:
    • Category A (Morse-Kelley + Tarski) is preserved in newchecker/09_entries.ML.
    • Category B (Hilbert calculus) is preserved in newchecker/05_rules.ML.
    • Category C (ThmWithoutPrf optimization) is preserved in newchecker/07_theorems.ML.
  • PDF & Binaries Immutability Rule: The module 10_pdf_generator.ML extracts listing source to CONTENT.ML. In accordance with platform rules, already compiled and stored PDF documents and binaries across all repositories must never be mutated or overwritten.
